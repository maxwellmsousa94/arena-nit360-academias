# Arena NIT 360 — Academias

Página do QR Code da campanha de pickleball da Arena NIT 360 para academias parceiras.
Aula experimental gratuita no Clube Espanhol (Niterói), agendada direto pelo WhatsApp.

- Para editar WhatsApp, endereço, mensagem e vídeo principal: bloco `CONFIG` no início do `<script>` do `index.html`.
- QR por academia: adicione `?academia=NomeDaAcademia` ao fim do link.
